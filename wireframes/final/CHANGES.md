# Changes

These changes follow the user testing of iteration 3.

## Final

- **Tasks:** one of the testers said the work matters more than the members shemselves
  that ideally should come first - so tasks now sit at the top of the group page. 
  Members/chat were moved to a smaller card on the right.
- **Chat:** testers asked for a group chat, as a tab beside Members. 
  This does go against my original personal UX feelings, which left 
  chat up to Discord (to not duplicate roles); but was added after user testing.
- **Notifications:** one tester suggested a notifications tab. Now a bell in the top
  right lists recent activity for all groups.
- **Assignment brief:** a tester asked for a link to the assignment or at
  least a summary of it.
- **UX and Design:** final touchups and design improvements before the final submission.
