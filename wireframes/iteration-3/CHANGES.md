# Changes

This iteration was about visual style, UX and readability (and at least an attempt at WCAG)

## Iteration 3

- **Components:** pill buttons, lists, rows and labels 
  reuse my (Dylan's) Project 2 style. Initials for members,
  and icons for actions and statuses.
- **Surfaces:** shading, shadows and spacing separate cards and rows.
- **Corners and alignment:** nested corner radii follow the spacing between
  surfaces. (I am very fussy about corner radius)
- **Status colours:** More clear colour for things that should have attention
  red for missing work, submission readiness on the
  group page and for Member 4 inactivity. Green marks the submission
  confirmation.
- **Logos:** GitLab, Google Drive and Discord logos added
- **Submission:** on desktop, deliverables appear beside a panel, 
  On mobile, the panel is below
- **Responsive:** Basic mobile support. at 960 or less use one column. 
- **Accessibility:** text and icon colours were adjusted for
  contrast, and keyboard focus has a ring (from project 2). 
  Basic accessability support in terms of increased contrast mode, Windows themes and
  'prefers reduced motion'. Not proper WCAG yet obviously 

Should be it for now?
